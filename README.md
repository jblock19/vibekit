# VibeKit

A guided workspace for turning app ideas into sequential AI-ready build prompts.

## Product idea

VibeKit helps people build apps with AI through progressive requirements instead of one giant requirements dump. The app guides users through templates, generates scoped build prompts, and helps track each build pass.

## Current state

Pass 1 is a static Product Intake Template.

It lets a user:

- Define a new app idea
- Capture the problem, audience, first action, vibe, references, and differentiation
- Select preferred helper tools
- Generate a markdown-style Product Brief v1
- Copy the brief for use in ChatGPT, Codex, Claude, or another coding assistant

## Files

## How to run

Open `index.html` in a browser.

No build step, backend, auth, or external API is required for Pass 1.

## Build principle

Progressive requirements, not giant specs.

The first app built with VibeKit is VibeKit itself.

## Next pass

Pass 2 should add the Core Loop Template and MVP Boundary Template, then generate the next scoped implementation prompt from those answers.
